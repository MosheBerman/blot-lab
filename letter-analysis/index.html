Letter Analysis

Two independent passes over the 1940–42 family letters, each examining the corpus against eight technique families (visible text, lighter words, markings, word skips, anagrams, religious code patterns, cryptography, WWI plain-sight conventions).

Muse pass (16 Oct 2026): 53 letters, fresh eyes, no prior conclusions. Claude pass (16 Oct 2026): 54 scans, 45 transcribed letters. Both found no cipher and no hidden writing; both document the plain-sight findings, and the Muse report adds a table of facts that should exist in an archive. Each report keeps its own page too.
